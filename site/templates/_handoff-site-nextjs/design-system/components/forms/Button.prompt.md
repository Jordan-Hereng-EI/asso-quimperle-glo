Pill-shaped call-to-action button in the Beninese flag palette; use for any primary or secondary action.

```jsx
<Button variant="primary" size="lg" iconAfter={<ArrowIcon />}>Faire un don</Button>
<Button variant="outline">En savoir plus</Button>
```

Variants: `primary` (green, default CTA), `highlight` (yellow, donate/urgent), `danger` (red), `outline`, `ghost`. Sizes: `sm` / `md` / `lg`. Pass `as="a"` + `href` for links, `block` for full width, `icon` / `iconAfter` for leading/trailing glyphs.
